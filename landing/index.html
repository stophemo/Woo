写作随想 · 7 月 28 日

让工具退后，让思考向前

好的写作工具，不应该把注意力放在自己身上。

它应该足够快，让念头出现时不必等待；也应该足够安静，让界面在文字开始之后慢慢退场。

写作不是把句子搬进软件，而是为思考留出一块不被打扰的地方。

保持简单，也保留余地

本地保存承担确定性，版本历史留住探索过程。云同步可以按需启用，但不应成为开始写作的前提。

写作不该被工具打断

从一个念头，到一篇完整文稿

01

开始写作 · 无需登录

先写下来，不等网络

文稿优先保存在当前设备。正式文稿写入 SQLite，未归档草稿留在应用本地；没有网络，也能继续浏览和编辑。

02

持续推进 · 自动保存

安心改，过程会留下

桌面端所见即所得编辑并自动保存，Android 端直接编辑 Markdown、确认后保存。正式文稿在保存过程中还会留下可恢复的版本记录。

03

设备切换 · 可选同步

换个地方，接着写

注册并登录后，正式文稿、文件夹与版本历史会增量同步。遇到跨设备内容冲突时，本地内容会尽量保留为副本。

克制，但不简陋

把能力放在需要的地方

Woo 不要求你先迁移工作流。编辑、整理、搜索、回溯和导出，都收在同一个安静的工作区里。

A

桌面所见即所得，也懂 Markdown

桌面编辑器支持标题、列表、引用、代码与表格；输入或粘贴 Markdown 后直接进入排版，不必在源码与预览间来回切换。

专注编辑
B

自动保存与版本历史

桌面端自动保存正文，并在空闲或切换文稿时记录版本；Android 保存正式文稿时也会记录版本。恢复旧版本前，当前内容仍会保留。

可回溯
C

内容进得来，也带得走

桌面端可以打开 Markdown 与纯文本文件，并将修改写回原文件；文稿还可导出为 Markdown、纯文本或 PNG 图片。

格式自由
D

从文件夹到内容结构

用多级文件夹和全文搜索整理文稿，用大纲快速定位标题；桌面端还可将层级列表预览并导出为思维导图。

结构清晰

同一份文字，不同的合适形态

桌面负责沉浸，手机负责随身

桌面端提供三栏工作区与所见即所得编辑；Android 则围绕浏览、搜索、Markdown 编辑和版本回溯重新组织，更适合小屏操作。
