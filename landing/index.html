个人写作 · 7 月 28 日

七月写作计划

这个月只做一件事：把三个零散主题写完整。

每天上午留出四十分钟，只推进一个段落。先写清楚，再决定哪些值得保留。

不追求一次成稿，先让每个想法都有落下来的地方。

本周安排

周一整理材料，周三完成初稿，周末留给重读和删改。每次停笔前，写下下一步从哪里开始。

本地写作流程

从落笔到续写，不让工具打断

01

无需注册 · 离线可用

打开就写

不用先创建账号，也不用等待网络。正式文稿和临时草稿都优先保存在当前设备，断网时仍可浏览和编辑。

02

自动保存 · 版本记录

每次修改，都有回头路

桌面端持续自动保存，并为正式文稿记录版本；Android 在确认保存时也会留下版本。需要回看时，当前内容不会被直接覆盖。

03

登录后开启 · 增量同步

换台设备，接着写

登录后可同步文件夹、正式文稿与版本历史。检测到跨设备内容冲突时，Woo 会尝试把当前内容另存为副本，方便核对。

编辑与整理

从落笔到整理，一处完成

直观编辑、快速定位、版本回溯和自由导出，都收在同一个工作区。需要时随手可用，其余时间不打扰写作。

A

所见即所得，也保留 Markdown 的效率

标题、列表、引用、代码块与表格都能直接排版。常用 Markdown 输入和粘贴会即时呈现，不必在源码与预览之间切换。

直接排版
B

自动保存，也能回看旧版本

桌面端自动保存正文，并按编辑节奏记录版本；Android 在确认保存时记录版本。恢复旧版本前，当前内容会先留档。

安心修改
C

文件能打开，内容能带走

桌面端可直接打开并写回 Markdown 与纯文本文件；应用内文稿也能导出为 Markdown、纯文本或 PNG 图片。

开放格式
D

长文也能快速定位

用多级文件夹和全文搜索整理文稿，用大纲跳转标题；桌面端还能将层级列表预览并导出为思维导图。

清晰组织

桌面与移动端

桌面深入写，手机随时接上

macOS 与 Windows 提供三栏工作区、所见即所得编辑与大纲；Android 聚焦浏览、搜索、Markdown 编辑和版本回溯，让小屏操作更直接。

数据与同步

本地保存是默认，同步是选择

不登录时，Woo 不会启用云同步，文稿默认保存在当前设备。登录后，你可以同步文件夹、正式文稿和版本历史；临时草稿仍留在设备本地。
