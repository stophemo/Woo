# WebDAV 与局域网同步

Woo 是本地优先的编辑器：所有文稿先写入本机 SQLite。跨设备同步只使用 **WebDAV**，
不再依赖 Supabase、云端账号或任何第三方服务。

WebDAV 是通用协议，Woo 不绑定服务商。坚果云、群晖、Nextcloud、Alist、自建 WebDAV，
以及桌面端内置的局域网 WebDAV 都可以直接使用。

---

## 一、WebDAV 同步

### 1. 准备

1. 找到你的 WebDAV 地址、用户名和密码：
   - 坚果云：`https://dav.jianguoyun.com/dav`，密码需在「账户信息 → 安全 → 应用密码」生成；
   - 群晖 / Nextcloud / Alist：在服务商控制台开启 WebDAV，复制地址与账号；
   - 其他服务：任何兼容 WebDAV 的地址都可以。
2. 在远端准备一个目录（也可以让 Woo 自动创建），默认使用 `Woo`。

### 2. 启用

1. 打开 Woo：手机端「我的 → WebDAV 同步」，桌面端「设置 → WebDAV 同步」。
2. 填入地址、用户名、密码和同步目录。
3. 点「测试连接」，成功后保存并启用。
4. 点「立即同步」。首次会把本地文稿上传到远端 `Woo/`。

坚果云免费版示例：每月 1GB 上传 / 3GB 下载，按自然月刷新；日常纯文字笔记足够用。

### 3. 同步规则

- 同步：目录、文稿（标题、正文、排序、回收站状态、锁定状态）。
- 不同步：版本历史、知识库分块、密码锁的密码哈希。版本历史和密码锁只保留在本机。
- 冲突：按 `update_time` 最后写入胜出；同一秒内两边都改过时用内容哈希做确定性决胜。
- 删除：进入回收站会同步；清空回收站后通过墓碑传播，墓碑保留 90 天。
- 网络：本地保存或目录变更后自动触发一轮同步，回到前台时也会补一轮；局域网约 10 秒、WebDAV 约 30 秒做一次兜底检查。清单未变化时只发一个 HEAD 请求。
- 限流：遇到 429/503 会暂停 5 分钟再试，不丢本地数据。

### 4. 远端目录

```
Woo/
├── manifest.json          索引 + 墓碑 + 每条记录的更新时间/哈希
├── documents/<id>.json    文稿
└── folders/<id>.json      目录
```

`manifest.json` 是唯一提交点：先传实体文件，最后写清单。中断时最多留下无害的孤儿文件。

### 5. 安全

- 密码以明文保存在应用私有目录（`webdav-config.json`，Unix 权限 0600）。
- 建议为 Woo 使用独立的 WebDAV 应用密码，不要复用其他服务。
- 数据存放在你自己的 WebDAV 里，不经过 Woo 的任何服务器。

## 二、局域网同步（完全离线）

桌面端内置一个只面向局域网的 WebDAV 服务，不需要互联网、云盘或服务器。

1. 电脑打开 Woo → 设置 → 局域网同步 → 启用。
2. 记下 6 位配对码；手动连接时还会显示地址（如 `http://192.168.1.23:45231`）、用户名 `woo`、局域网密码和目录。
3. 手机与电脑连同一个 Wi-Fi，在「我的 → WebDAV 同步」→「电脑配对」输入 6 位配对码，点「配对并连接」。手机会通过 UDP 广播发现电脑，自动填入地址、令牌和目录并开始同步。
4. 若网络屏蔽广播，可展开「连接」手动填入地址、用户名 `woo`、局域网密码和目录，测试连接后保存启用。

电脑上的 Woo 需要保持运行；关闭应用后局域网同步停止。配对码只用于局域网发现，不参与 WebDAV 认证；手动连接密码错误时 WebDAV 返回 401。
局域网内走明文 HTTP，请只在可信 Wi-Fi 使用。同步是双向的：每一轮都同时拉取和推送，单条记录按更新时间最新胜出。

## 三、从旧云账号迁移

- Supabase 登录/同步已经从运行时移除，不再发起任何 Supabase 网络请求。
- 每台设备现在固定使用一个 `woo.db`；启动不再读取本地会话，也不会切换到 `woo-{user}.db`。
- 旧版本留下的 `woo-{user}.db` 仍在数据目录中，但不会被自动打开；需要保留旧账号文稿时，请先备份并手工合并，或让应用在旧版本中同步到你的 WebDAV 后再用新版本拉取。
- 在 WebDAV 设置里启用并同步一次，即可把当前本地数据库上传到你自己的 WebDAV。
- 版本历史、密码锁不参与 WebDAV 同步。

## 四、排错

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `WebDAV 认证失败` | 密码填错 | 坚果云需使用「应用密码」，不是登录密码 |
| `云盘请求过于频繁` | 触发请求限制 | 等 5 分钟，应用会自动重试 |
| `云端同步清单损坏` | manifest 被外部工具改坏 | 备份远端目录后删除 `manifest.json`，重新同步会重建 |
| 局域网连不上 | 不在同一 Wi-Fi / 电脑应用未运行 | 确认同一网段、电脑上的 Woo 正在运行 |
| 新设备拉不到数据 | 地址/目录/账号不同 | 三者在所有设备上必须完全一致 |
